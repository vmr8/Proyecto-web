Política de privacidad del evento

Información recogida

El sitio puede recopilar los siguientes tipos de información:

Datos personales: nombre, correo electrónico, número de teléfono, edad, municipio o institución.

Datos técnicos: dirección IP, tipo de navegador, sistema operativo y tiempo de visita.

Datos de participación: formularios de inscripción, comentarios, encuestas o solicitudes de información.

Finalidad del tratamiento de datos

Los datos se utilizan para gestionar inscripciones y participación en el festival, enviar información sobre actividades, horarios y resultados, mejorar la experiencia del usuario en el sitio web y cumplir obligaciones legales y de seguridad

Base legal

El tratamiento de datos se realiza conforme a la legislación vigente sobre protección de datos personales y con el consentimiento explícito del usuario.

Conservación de datos

Los datos personales se conservarán únicamente durante el tiempo necesario para cumplir las finalidades descritas o mientras el usuario mantenga relación con el evento.

Enlances externos

El sitio puede incluir enlaces a páginas de terceros. El festival no se responsabiliza por las prácticas de privacidad ni el contenido de esos sitios externos.

Modificación de políticas

El festival se reserva el derecho de modificar esta política en cualquier momento. Las actualizaciones se publicarán en esta misma página con la fecha de revisión correspondiente.

Contacto

Para cualquier consulta relacionada con la privacidad o el tratamiento de datos personales, los usuarios pueden escribir a:📧 privacidad@festivaljoropo.com
