Joropo Vibes Fest - Sitio Web Oficial

Descripción de la web

Esta página web corresponde al proyecto Joropo Vibes Fest, un festival juvenil centrado en la cultura y tradición llanera. El sitio web ofrece una experiencia interactiva para los usuarios mediante las siguientes secciones:

Página de Inicio: Presentación general del evento, cartel informativo, itinerario detallado de actividades por días y listado de patrocinadores.

Preguntas Frecuentes (FAQ): Respuestas a las dudas más comunes de los asistentes sobre horarios, entradas y ubicación.

Formulario de Registro: Sección para que los participantes puedan inscribirse en el evento.

Galería y Contacto: Espacios dedicados a contenido visual del festival y vías de comunicación directa.

Tecnologías utilizadas

HTML5 para la estructuración y contenido del sitio web.

CSS3 para la presentación visual, diseño responsivo y estilos.

JavaScript para la interactividad de la página.

Visual Studio Code como entorno de desarrollo integrado (IDE).

Firebase Hosting para el alojamiento y publicación en la nube.

Indicaciones para abrirla o ejecutarla localmente

Para ejecutar y visualizar este proyecto de forma local en tu ordenador, sigue estos pasos:

Abre Visual Studio Code en tu equipo.

Ve al menú Archivo y selecciona Abrir carpeta para cargar la carpeta raíz de tu proyecto donde se encuentran los archivos index.html, CSS, JS e imágenes.

Para visualizar la web en el navegador, puedes elegir una de las siguientes opciones:

Opción recomendada: Instala la extensión Live Server en Visual Studio Code, haz clic derecho sobre el archivo index.html y selecciona Open with Live Server.

Opción directa: Abre tu explorador de archivos local, navega hasta la carpeta del proyecto y haz doble clic sobre el archivo index.html para abrirlo en tu navegador predeterminado.
